# 3.6 Design constraints

## Process and modules

**DES-01** Vakthund v0.1 MUST run as one process containing the modules `net`, `chain` and `block-sync`.

## Module boundaries

Modules are kept separable so that each interaction can later be carried by a message bus instead of a call or a queue.

**DES-02** A module MUST access another module only through that module's interface
([net](3.2.1-net.md#interface), [chain](3.2.2-chain.md#interface)) or by pushing to its queue.

**DES-03** No module MUST hold references into another module's state or storage. Every call argument, return value
and queue item MUST be owned data.

**DES-04** Each module MUST own its stores exclusively (STO-04).

**DES-05** `chain` MUST call no other module. `net` MUST call no other module; it only pushes routed messages into
queues. `block-sync` exposes no calls (BSY-04).

## Queues

**DES-06** Every queue MUST be bounded. A message MUST never be dropped from a queue: a full queue is a node failure
(ATT-01).

## Engine

**DES-07** Every store MUST be a separate RocksDB [R18] instance in its own directory
([Table 3.5-1](3.5-logical-database.md#stores)).

**DES-08** Every table MUST use the tuning profile assigned to it in [3.5](3.5-logical-database.md), from Table 3.6-1.

Table 3.6-1. Tuning profiles

| Profile      | Used for                           | Settings     |
|--------------|------------------------------------|--------------|
| point lookup | tables read by key                 | bloom filter |
| large values | tables of large values read by key | blob files   |
| sequential   | tables read in key order           | —            |

**DES-09** Writes whose order is required by [write ordering](3.5-logical-database.md#write-ordering) MUST use RocksDB
sync mode (`WriteOptions::set_sync(true)`).

## Components

**DES-10** Bitcoin data structures and consensus encoding MUST come from rust-bitcoin [R15].

**DES-11** P2P message types and framing MUST come from `bitcoin-p2p-messages` [R16].

**DES-12** Script verification MUST use the C bindings of Bitcoin Core [R17].
