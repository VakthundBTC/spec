# 3.7 Software system attributes

## Reliability

**ATT-01** A full queue is a node failure: the node MUST stop.

**ATT-02** A consensus failure (a block invalid under consensus rules while its header is valid) MUST be reported by
`block-sync`, and the node MUST stop.

**ATT-03** After a stop during a reorg, the node MUST relaunch in standard mode (BSY-28).

**ATT-04** A rejected block MUST leave the stores unchanged (CHN-15).

**ATT-05** Every write to a store MUST be atomic (STO-01), and cross-store consistency MUST follow the write ordering
(STO-05).

## Security

**ATT-06** The node MUST connect only to configured peers (NET-03), MUST treat them as trusted (NET-04), and MUST NOT
accept inbound connections (EXT-02).

## Maintainability

Modules are kept separable (DES-02 to DES-05) so that each interaction can later be carried by a message bus.
